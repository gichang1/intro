# Bio Food Tech Operations Terminal

농촌진흥청 연구정책국 바이오푸드테크팀 업무 소개 페이지.
사이버펑크 스타일의 단일 HTML 페이지로, 별도 빌드 과정 없이 그대로 배포됩니다.

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 사이트 전체 (HTML · CSS · JS 인라인) |
| `.nojekyll` | GitHub Pages의 Jekyll 처리 비활성화 |

## 로컬에서 보기

`index.html` 파일을 브라우저로 열면 됩니다. 서버가 필요하지 않습니다.

## 수정 방법

색상, 폰트, 애니메이션 속도는 `index.html` 상단 `:root` 블록의 CSS 변수에 모두 모여 있습니다.

```css
--cyan:#00f0ff;    /* 데이터, 테두리 */
--magenta:#ff2e88; /* 라벨, 강조 */
--lime:#39ff14;    /* 살아있는 것 — 활성 상태, 바이오 정체성 */
```

본문 내용은 각 `<section>` 안에 한글 주석과 함께 구분되어 있습니다.

연락처는 `#end` 섹션의 `[ 연락처를 여기에 입력 ]` 부분을 교체하세요.

## 설계 원칙

- 다크 단일 테마. 라이트 모드 없음
- 모바일 360px 폭까지 가로 스크롤 없이 동작
- `prefers-reduced-motion` 지원 — 켜져 있으면 타이핑·글리치·진입 애니메이션 정지
- 본문 텍스트는 네온색을 쓰지 않고 대비비 확보

## 고지

개인이 제작한 업무 소개 페이지이며, 소속 기관의 공식 입장이 아닙니다.
외부 공개를 전제로 구성되어 예산 금액, 과제번호, 내부 인력 정보, 미확정 기획사업의
구체적 규모는 포함하지 않았습니다.
